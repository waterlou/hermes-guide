# Slash Commands

Slash commands are special commands you can type during a conversation to perform actions. Type `/` followed by the command name.

---

## General Commands

| Command | Description |
|---------|-------------|
| `/help` | Show all available commands |
| `/clear` | Clear the current conversation screen |
| `/save` | Save the current conversation |
| `/quit` or `/exit` | End the session |
| `/stats` | Show conversation statistics |

---

## Model & Provider

| Command | Description |
|---------|-------------|
| `/model` | Switch the active model interactively |
| `/provider` | Switch the LLM provider |
| `/temp <value>` | Set temperature (0.0 - 1.0) |

---

## Tools

| Command | Description |
|---------|-------------|
| `/tools` | List all available tools |
| `/tools enable <name>` | Enable a specific tool |
| `/tools disable <name>` | Disable a specific tool |
| `/tool <name>` | Use a specific tool directly |

---

## Memory

| Command | Description |
|---------|-------------|
| `/memory` | View memory system status |
| `/memory recall <query>` | Search past conversation memory |
| `/memory forget` | Clear current session memory |
| `/memory stats` | Show memory usage statistics |

---

## Skills

| Command | Description |
|---------|-------------|
| `/skills` | List active skills |
| `/skills load <name>` | Load a specific skill |
| `/skills unload <name>` | Unload a specific skill |

---

## Voice

| Command | Description |
|---------|-------------|
| `/voice on` | Enable voice input mode |
| `/voice off` | Disable voice input mode |
| `/voice status` | Check voice configuration |

---

## Files & Code

| Command | Description |
|---------|-------------|
| `/code` | Enter code-focused mode |
| `/file <path>` | Load or reference a file |
| `/image <path>` | Load an image for analysis |

---

## Gateway (Messaging)

| Command | Description |
|---------|-------------|
| `/gateway status` | Check gateway connection status |
| `/gateway reconnect` | Reconnect gateway platforms |

---

# 斜線指令

斜線指令是您在對話中可輸入的特殊指令，用於執行特定操作。輸入 `/` 後接指令名稱即可使用。

---

## 一般指令

| 指令 | 說明 |
|------|------|
| `/help` | 顯示所有可用指令 |
| `/clear` | 清除當前對話畫面 |
| `/save` | 儲存當前對話 |
| `/quit` 或 `/exit` | 結束對話 |
| `/stats` | 顯示對話統計資訊 |

---

## 模型與提供者

| 指令 | 說明 |
|------|------|
| `/model` | 互動式切換啟用中的模型 |
| `/provider` | 切換 LLM 提供者 |
| `/temp <數值>` | 設定溫度 (0.0 - 1.0) |

---

## 工具

| 指令 | 說明 |
|------|------|
| `/tools` | 列出所有可用工具 |
| `/tools enable <名稱>` | 啟用特定工具 |
| `/tools disable <名稱>` | 停用特定工具 |
| `/tool <名稱>` | 直接使用特定工具 |

---

## 記憶

| 指令 | 說明 |
|------|------|
| `/memory` | 檢視記憶系統狀態 |
| `/memory recall <查詢>` | 搜尋過去對話記憶 |
| `/memory forget` | 清除當前對話記憶 |
| `/memory stats` | 顯示記憶使用統計 |

---

## 技能

| 指令 | 說明 |
|------|------|
| `/skills` | 列出啟用中的技能 |
| `/skills load <名稱>` | 載入特定技能 |
| `/skills unload <名稱>` | 卸載特定技能 |

---

## 語音

| 指令 | 說明 |
|------|------|
| `/voice on` | 啟用語音輸入模式 |
| `/voice off` | 停用語音輸入模式 |
| `/voice status` | 檢查語音設定 |

---

## 檔案與程式碼

| 指令 | 說明 |
|------|------|
| `/code` | 進入程式碼專注模式 |
| `/file <路徑>` | 載入或參考檔案 |
| `/image <路徑>` | 載入圖片進行分析 |

---

## 閘道（訊息平台）

| 指令 | 說明 |
|------|------|
| `/gateway status` | 檢查閘道連線狀態 |
| `/gateway reconnect` | 重新連線閘道平台 |
